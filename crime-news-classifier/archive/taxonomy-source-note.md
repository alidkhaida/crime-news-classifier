# Taxonomy Source Note

This note records the provenance of the local recognition taxonomy. It is not loaded during normal classification.

The local primary taxonomy was derived from the client-supplied Google Doc **CRIME CATEGORIES - ROUGH DRAFT**:

https://docs.google.com/document/d/1sW9nyDPfRop1UsD2iF1D7ySJw18r3W-mGA1gZWUJPRo/edit

Runtime category selection uses the local compact files in `references/primary-taxonomy.md` and `references/category-selection.md`. The external document is retained here for historical provenance and future reconciliation only. Do not require external document access during a classification run.
